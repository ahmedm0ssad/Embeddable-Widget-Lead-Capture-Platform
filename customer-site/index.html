How to use this page

  1. Run the API: docker compose up --build
  2. Seed demo data: python -m scripts.seed_demo
  3. Serve this page from a second origin: python -m http.server 5500
  4. Open http://localhost:5500/?widget=<widget-id>

When no widget query parameter is provided, the page looks up the demo widget IDs from GET /widgets (Bearer auth) or you can paste an id directly.
